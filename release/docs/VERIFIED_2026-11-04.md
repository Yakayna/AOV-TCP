# Xác minh mới — 04/11/2026 (gateway login)

Tất cả số liệu dưới đây lấy từ capture app thật (bản 1.64.1.11, không mod) và từ
disassembly `libgcloud.so` (md5 `2d023cdcdd0b52786b122fc65893568f`).

## 1. `0x2001` — plaintext CHÍNH XÁC là 64 byte

Giải mã body `0x2001` của app (key phiên lấy từ `0x1002`) ra đúng:

```
ptlen 64
"2b0dd61b7eada2292835dc6ca4a32bcde6891d"   38 ký tự hex của token (token[2:40])
+ 19 byte 0x00
+ 0x17        (padlen)
+ "tsf4g"     (tag)
+ 0x07
```

Frame tương ứng: `hl=21`, `bl=80` (iv 16 + ciphertext 64), header

```
336600080008200100000000020000001500000050
```

⇒ Đã sửa `release/tools/clientless_lobby_replay.py` và `tools/lobby_hold.py` sang layout này
(trước đó dùng `token[2:]` 64 ký tự + filler ngẫu nhiên + trailer khác ⇒ server trả
`S-Stop 0xffffd8ee` = malformed 0x2001).

## 2. HEAD / tail — khớp app 100%

Giải mã IV của frame `0x2001` thật:

```
fffe02073534353008360b0b2547 3e69
└──────── HEAD ────────────┘ └tail┘
```

Tail là **per-account**, không đổi giữa các phiên. Brute 16-bit bằng 96 thread tìm ra
trong ~4 phút (test thật: tail `6b36` cho một acc mới mint).

## 3. Không có MAC / checksum trong frame

`0x1fe1c0` (`taes_encrypt_pad`) chèn filler bằng `rand()`, vòng lặp `0x1fe2b8–0x1fe2d0`
gọi `rand@plt`; `0x1fe3b0` (unpad) chỉ đọc `tsf4g` + padlen. 8.517 datagram: 1.976 tổ
hợp CRC/hash → 0 hit.

## 4. Gate lobby KHÔNG nằm trong lib

`0x1e9808` xử lý `0x2002`/`0x6002` **không gửi frame nào**; `0x202be0` chỉ gửi data khi
`state >= 5`. Blob session `ctx+0x178c` là write-only. Chuỗi `fffe0207…` không có trong
bất kỳ .so nào của game ⇒ tail do app-layer tạo, server kiểm tra.

## 5. Kết quả chạy thật (04/11)

```
$ python -m aov.login --token-json token.json --tail 6b36 --gw <gw>
[recv] cmd=0x2002 len=133
[recv] cmd=0x6002 len=53
[key] b'...'
[login] ok=True commands=['0x2002', '0x6002'] lobby_frames=2
```

Login vào gateway: ✅. Stream lobby: vẫn ❌ (xem mục “Blocker” trong README — server-side
trust, khớp với kết luận cũ).
